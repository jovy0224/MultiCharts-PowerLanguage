# 突破+50-20 by Angel chen

日盤當沖策略：以 09:15 當天開盤價為基準，上下各 30 點掛停損單雙向突破，13:00 後強制平倉。

## 邏輯
- 09:15 記錄當天開盤價 `value1`
- 09:15–13:00 之間，在 `value1+30` 掛買進停損單、`value1-30` 掛放空停損單
- 13:00 之後強制平倉
- `setstoploss(40*bigpointvalue)` 固定金額停損

## 這次修復的 bug
- 原本用 `time=0915` 精準比對抓開盤價，若資料剛好沒有那一根K棒，`value1` 會整天停在 0，
  停損單價位變成 0±30 這種離譜的價位；已改用 `time>=0915` + 旗標，並補上每日重置。
- 原本進場單完全沒檢查 `marketposition`，等於每根K棒都會重複送單／翻倉；已加上 `marketposition=0` 閘門。

## 關鍵參數（目前寫死在程式碼裡，還沒做成 input）
| 名稱 | 值 | 說明 |
|---|---|---|
| 開盤時間 | 0915 | 記錄基準價的時間點 |
| 進場窗口 | 0915–1300 | |
| 突破點數 | ±30 | 相對開盤價的停損單距離 |
| 停損 | 40×bigpointvalue | |

檔名寫「+50-20」但程式碼實際用的是 ±30，兩者對不上，如果你手上有原始「+50/-20」版本，
可以告訴我要不要改回那組數字。

## 建議 Workspace/Chart 設定
- **商品**：日盤期貨（例如 TXF）
- **週期**：分鐘K
- **Session**：Format Symbol > Session Template 選日盤
- **口數**：於 Format Strategy > Properties 自行設定

通用匯入步驟見 `docs/SETUP.md`。
