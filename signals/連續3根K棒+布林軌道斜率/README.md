# 連續3根K棒+布林軌道斜率

日盤策略：連續 3 根K棒同方向（開高走高或開低走低），且布林通道上/下軌同步同方向，
才順勢突破近 5 根高/低點進場；13:10 後改用近 3 根高低點追蹤停損，13:35 市價平倉。

> **注意**：這個檔案跟 `signals/連續K棒上漲下跌ey90223/strategy.pla` 內容完全相同，
> 只是檔名不同（推測是網路上收集到的兩個來源）。目前先各自獨立成資料夾方便你各自開一個
> workspace 測試，如果你確定是重複的，之後可以告訴我要不要合併成一支、刪掉一份。

## 關鍵 inputs
| input | 預設 | 說明 |
|---|---|---|
| Length | 20 | 布林通道天期 |
| NumDevsUp | 2 | 上軌標準差倍數 |
| NumDevsDn | -2 | 下軌標準差倍數 |

## 建議 Workspace/Chart 設定
- **商品**：日盤期貨（例如 TXF）
- **週期**：分鐘K
- **Session**：Format Symbol > Session Template 選日盤（出場邏輯用到 1310/1335）
- **口數**：於 Format Strategy > Properties 自行設定

通用匯入步驟見 `docs/SETUP.md`。
