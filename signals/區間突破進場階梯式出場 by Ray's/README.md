# 區間突破進場階梯式出場 by Ray's

日內策略：開盤 N 根K棒的區間高點突破做多，出場採用階梯式移動停損
（進場後只要創新高，出場價就往上跟到「當根與前一根低點取最低」）。

## 邏輯
- 開盤第 N 根K棒收盤時，記錄前 N 根的高點 `kh`
- 之後收盤價向上突破 `kh` 且當天還沒做過（`k1<1`）→ 做多
- 進場後只要創新高，`buyexit` 就更新為當根/前根低點的最低值
- 收盤價跌破 `buyexit` → 出場
- 當天K棒數超過 `EODBars` → 強制平倉（保護機制，原始邏輯用「根數」而非時間）

## 這次修復的 bug
- 移動停損那段原本沒有檢查是否已經進場，會用 `barsSinceEntry(0)=-1` 去呼叫
  `highest()`，可能導致執行錯誤；已加上 `marketposition>0` 保護。

## 關鍵 inputs
| input | 預設 | 說明 |
|---|---|---|
| N | 12 | 開盤區間根數 |
| EODBars | 55 | 強制平倉的根數門檻（**注意：是根數不是時間**，若你的K棒週期跟原作者不同，55根對應的時間點也會不同，建議照下面的 Session 說明換算或自行調整） |

## 建議 Workspace/Chart 設定
- **商品**：日內策略，建議用日盤期貨（例如 TXF）
- **週期**：跟原作者一致的分鐘K（程式碼用「當天第幾根K棒」判斷，週期改變會影響 N 和 EODBars 對應的實際時間）
- **Session**：Format Symbol > Session Template 選日盤
- **口數**：於 Format Strategy > Properties 自行設定

通用匯入步驟見 `docs/SETUP.md`。
